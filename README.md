# 📌 About Project

The **To-Do List App** helps users organize their daily tasks efficiently. Users can add tasks, mark them as completed, delete tasks, and clear all tasks with a simple and user-friendly interface.


# ✨ Features

✅ Add New Tasks  
✅ Mark Tasks as Completed  
✅ Delete Individual Tasks  
✅ Clear All Tasks  
✅ Responsive Design  
✅ Dark Theme UI  
✅ Fast and Lightweight  
✅ Beginner-Friendly Project

# 🎯 How It Works

1. Enter a task.
2. Click **Add**.
3. Mark completed tasks using ✔.
4. Delete unwanted tasks using ❌.
5. Use **Clear All** to remove all tasks.
